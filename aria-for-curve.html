Workflows

Why add Aria to Curve?

Curve solved the cloud-PMS problem for clinical workflows. Aria solves the always-on receptionist problem for the front office. The two are complementary — Curve continues to be your clinical and operational source of truth, Aria handles the patient-facing communication layer.

Frequently asked questions

Does Aria work with Curve Hero on any browser?
Aria itself is independent of the browser you use to access Curve. The integration is API-level.
What about Curve GRO (their messaging product)?
GRO is Curve's first-party SMS marketing tool. Aria's SMS focuses on confirmations, reminders, and reviews — different use case. Many practices run both.
Will adding Aria slow down Curve?
No. Aria is a separate cloud product calling Curve's API on demand. There's no shared infrastructure or shared database layer to slow down.
Can Aria handle multi-location Curve setups?
Multi-location routing is on the Q4 2026 roadmap. Single-location practices can deploy today.
